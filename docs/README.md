# EndoMR-PREG Documentation

## Mendelian Randomization Analysis: Endometriosis and Pregnancy Outcomes

### Project Overview

This repository contains a comprehensive Mendelian Randomization (MR) analysis investigating the causal relationship between genetic liability to endometriosis and various pregnancy outcomes.

### Table of Contents

- [Methodology](methodology.md) - Detailed methods and statistical approaches
- [Results Summary](results.md) - Main findings and interpretations  
- [Supplementary Material](supplementary.md) - Additional analyses and tables
- [Code Documentation](code-documentation.md) - Guide to analysis scripts
- [Data Sources](data-sources.md) - GWAS data sources and references

### Quick Start

1. **Data Preparation**: Run scripts 1-3 to prepare and harmonize data
2. **Main Analysis**: Execute script 4 for primary MR analysis
3. **Visualization**: Use scripts 5-7 for tables and plots
4. **Results**: Check `/results/` and `/plot/` folders for outputs

### Key Findings

- **Significant associations** identified for:
  - Female infertility (FinnGen)
  - Premature rupture of membranes
  - Placenta praevia (FinnGen)
  - Placental abruption (FinnGen)
